=== 1. Ask OpenSSL to write the TPM key ===

$ head -1 /tmp/tpm-lab/node01-export-attempt.pem
-----BEGIN TSS2 PRIVATE KEY-----

Despite its name, 'TSS2 PRIVATE KEY' is a TPM object container.
It contains a public area and an encrypted private area, not the EC
private scalar. It can perform private operations only through its TPM.
